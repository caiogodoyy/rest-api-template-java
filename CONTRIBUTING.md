# Contributing Guidelines

Thanks for contributing to our Java REST API template! Your contributions help make this project even better.

## How to Contribute

### 🚀 Getting Started

1. **Fork** the repository.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/caiogodoyy/rest-api-template-java.git
   cd rest-api-template-java
   ```
3. **Create a new branch** for your feature or bug fix:
  ```bash
  git checkout -b feature/your-feature-name
  ```
4. Make your changes and ensure the code builds successfully:
  ```bash
  ./mvnw clean install
  ```
5. Run tests and ensure they pass:
  ```bash
  ./mvnw test
  ```
6. **Commit** your changes with clear, descriptive commit messages:
  ```bash
  git commit -m "Add your descriptive commit message"
  ```
7. **Push** your branch to your fork:
  ```bash
  git push origin feature/your-feature-name
  ```
8. **Open** a pull request (PR) to merge your changes into the main or develop branch.

## Commit Message Guidelines

- Use clear and descriptive commit messages.
- Start with a capitalized verb (e.g., `Add`, `Fix`, `Update`).

## Reporting Issues

Report bugs or suggest enhancements by opening an issue. Please include details like steps to reproduce and expected behavior.

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) to maintain a welcoming and respectful community.

Thanks for your contribution!
